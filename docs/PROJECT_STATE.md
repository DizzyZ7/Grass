## Что есть в коде

- FastAPI-сервер с единой точкой входа и маршрутом webhook от aiogram 3.
- Telegram initData: обязательная HMAC-SHA256 проверка с постоянновременным сравнением и TTL 24 ч, пользователь только из подписанных данных.
- PostgreSQL ORM и первая Alembic-миграция: player, session, receipt с уникальным batch UUID и achievement unlock.
- Полностью клиентская анимация Canvas 2D: отдельная пружина каждой травинки, направленные касания, ветер, плавная палитра, частицы, цветочки, reduced-motion.
- 90-секундные сессии, отправка касаний небольшими пакетами ~2,8 с, клиентский outbox в localStorage на случай повторной отправки.
- Начисление опыта только сервером: <=18 касаний/сек + ограниченный начальный burst, 2500 касаний/сессию, 5-минутное окно закрытия. На отклоненные количества запись flags и предупреждение в лог.
- В начальном прогрессе 1 локация, 8 достижений в каталоге, уровни и 120 оригинальных фраз по 6 событиям.
- Из Telegram работает открытие Mini App из /start и кнопки в меню; шаринг текста с рекордом.
- Dockerfile: node:22 Alpine сборка Vite → python:3.12 slim single FastAPI service, миграция перед запуском.

## Важные ограничения

- Клиентские движения нельзя физически доказать на сервере. Ограничители защищают баланс, а не гарантируют отсутствие ботов.
- LocalLimiter действует внутри одного процесса. При нескольких инстансах нужен edge Redis/global limiter и централизованная миграция.
- `DEV_MODE=true` только локально. В публичном окружении каждый запрос должен проходить Telegram HMAC.
- Сырой initData, токены и приватные пользовательские данные никогда не должны попадать в общие логи.
